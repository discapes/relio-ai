## Boundaries and migration

Transcript dependency propagation stops at an explicit different named subject or topic transition, and bridges at most five non-referential speaker turns between established references. This removes the demonstrated long chains and fragmented quotes while preserving independently named subjects. Arbitrary semantic references across unrelated topics remain a limitation; deterministic erasure cannot prove complete natural-language coreference resolution. Existing paragraph, identity, metadata, derived-artifact and suppression cleanup still applies.

The session-signing key is `DATA_DIR/.session-secret`, outside immutable releases and Git, created atomically with mode 0600. Preserve it together with the SQLite data. The first visit with an old unsigned cookie starts a fresh demo and displays a one-time session-upgrade notice. Existing workspace rows remain unchanged; unsigned legacy identifiers are never adopted. Simulated employee/access selection remains an intentional hackathon feature within each signed browser workspace.

Latest-meeting selection uses permitted archive transcript dates. Customer scope uses the corpus's customer-shareable transcript classification. It does not infer that the selected employee attended, and it retains date ties. Request classification and generated summaries remain model decisions; exact source binding validates provenance but cannot guarantee exhaustive or correct semantic coverage for every arbitrary question.

Provisional factual text remains visibly labelled as awaiting source checks. Erased-identity suppression runs before that draft becomes visible. Contextual identity descriptions that cannot be resolved to stored suppression tokens retain the erasure limitation described above.

## Follow-on receipt rendering

The ROI retest exposed two further implementable defects: empty `[-]` citation remnants and a missing decimal continuation. The final renderer now removes empty punctuation-only citation markers. Receipt binding completes syntactically unfinished adjacent transcript fragments from the same speaker, preserving every original record ID and exact quote. It stops at a completed sentence, a different speaker or a missing ordinal, including an erasure gap. A controlled workflow reproduces the QBR statement citing utterance 0006 (ending “three,”) and now includes utterance 0007 (“point two.”). The original live artifact remains unchanged as evidence of what was actually returned before this follow-on fix.

This completion rule addresses source fragmentation; it does not establish semantic entailment or resolve cross-speaker interruptions. The model verifier can still overlook a relevant passage or make an attribution mistake. Existing practice-answer coverage limits therefore remain documented.

## Verification

The final fix build passed 68 deterministic tests, Svelte checks with zero errors/warnings and a production build. Twelve browser workflows passed together, followed by the added one-time session-upgrade test. The independent captured-output replay checked exact receipt quotes and the missing decimal continuation. Deployment details are recorded in `VALIDATION.md`. The independent reviewer owns the actual latest-meeting and ROI retests and appends their results to the review report. Browser tests use isolated data and controlled streaming fixtures; they do not consume additional live inference.
