# Starter walkthrough

This is a foundation demo, not a challenge submission pitch.

1. Open Overview: inspect the shared shell, typography, cards and Signal Room palette.
2. Search the sample collection and filter by status; try a query with no results.
3. Open the detail dialog and dismiss it with Escape.
4. Open Settings, save a workspace name and reload to demonstrate persistence.
5. View at mobile width; navigation and cards rearrange without horizontal page scrolling.

Next: choose a product workflow before introducing domain schema, data ingestion or model services.
